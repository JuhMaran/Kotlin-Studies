# Kotlin Studies

Este repositório reúne projetos e exercícios desenvolvidos durante meus estudos da linguagem **Kotlin**.  
O objetivo é praticar conceitos fundamentais da linguagem, explorar suas principais funcionalidades e consolidar conhecimentos aplicados ao desenvolvimento de software.

Os projetos presentes aqui foram desenvolvidos com base nos cursos:

- [Dominando o Kotlin: uma base sólida para iniciantes](https://www.udemy.com/course/dominando-o-kotlin-uma-base-solida-para-iniciantes/)
- [Desenvolvimento Android Completo - Kotlin & Java](https://www.udemy.com/course/desenvolvimento-android-completo/)

Ao longo deste repositório você encontrará exemplos práticos, pequenos projetos e exercícios que abordam desde **fundamentos da linguagem** até conceitos utilizados no **desenvolvimento Android**.
